## Pipeline 状态流转

```
线索捕获 → BANT认证 → CRM录入 → 调研丰富
    → 报价 → 谈判 → 汇报 → 培育/售后
    → 邮件序列 → 多渠道编排
```

**完整状态流：**
```
new → contacted → interested → quote_sent → negotiating → meeting_set → closed_won / closed_lost / nurture
new → email_sent → email_replied → contacted → ... (邮件触达路径)
```

**状态定义：**

| 状态 | 含义 | 进入条件 |
|------|------|---------|
| `new` | 新线索 | CRM 记录创建 |
| `contacted` | 已联系 | 首条消息/邮件发出 |
| `interested` | 有兴趣 | 客户回复表示兴趣 |
| `quote_sent` | 报价已发 | 报价邮件/WhatsApp 发出 |
| `negotiating` | 谈判中 | 客户有还价/讨论条款 |
| `meeting_set` | 约见已定 | 确认电话/视频会议时间 |
| `email_sent` | 开发信已发 | 冷线索邮件序列首封发出 |
| `email_replied` | 邮件已回复 | 客户回复开发信 |
| `closed_won` | 成交 | 订单确认/定金收到 |
| `closed_lost` | 失单 | 客户明确拒绝/选择竞品/不回复 |
| `nurture` | 培育中 | cold_lead / 失单 / 长期无互动 |

## 线索分级

| 分级 | 条件 | 跟进策略 |
|------|------|---------|
| **hot_lead** | BANT ≥ 3/4 AND ICP ≥ 75 | 24h 内首触，每 3 天跟进 |
| **warm_lead** | BANT 2/4 OR ICP 50-74 | 48h 内首触，每 5 天跟进 |
| **cold_lead** | BANT ≤ 1/4 AND ICP < 50 | 培育池，每 2 周触达 |

## ICP 定义速查

> 详见 USER.md 完整定义

| 维度 | 权重 | 高分条件 |
|------|------|---------|
| 企业规模 | 30% | 500+ 人 / 年营收 500 万美元+ |
| 行业匹配 | 25% | 传送带 / 皮带 / 制造业 |
| 采购历史 | 20% | 有进口记录 |
| 付款能力 | 15% | T/T 预付能力强 |
| 决策链 | 10% | 直接找到采购总监 |

**评分分级：**
- 75-100: A级 → 直接触达，优先发开发信
- 50-74: B级 → 观察跟进，等待更好时机
- 30-49: C级 → 培育池，周期性触达
- <30: D级 → 暂不触达（除非客户主动联系）

**禁止项：**
- 矿业直接客户（终端用户）→ ICP 自动归零，标记 `mining_blocked`，不触达
- 矿业贸易商（非终端用户）→ 正常 ICP 评分流程

## 铁律速查

| 铁律 | 规则 | 违反后果 |
|------|------|---------|
| **邮箱铁律** | 必须决策人邮箱，禁用 info@/sales@/contact@ | 开发信无效，浪费额度 |
| **ICP 铁律** | ICP ≥ 75 才发邮件 | 低质量线索浪费资源 |
| **开发信评分铁律** | ≥ 9.0 分才发送 | 垃圾邮件风险 |
| **报价锁定铁律** | 客户问价必须锁对话等审批，不能直接给数字 | 泄露定价策略 |
| **授权矩阵铁律** | 超出授权必须升级，不能擅自决定 | 可能造成财务损失 |
| **矿业禁止铁律** | 禁止接触矿业终端客户（贸易商除外） | 合规风险 |
| **无邮箱铁律** | 无法获取决策人邮箱则不继续深度开发 | 无效线索 |
| **WhatsApp 72h 铁律** | 72h 窗口外禁止主动推送，切换渠道 | 被封号风险 |
