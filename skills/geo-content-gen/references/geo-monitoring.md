## AI 搜索引擎引用检查流程

**执行频率:** 每周一次

**检查关键词:** 从 keyword-matrix.md 中选取核心关键词（每次 5-10 个）

**检查平台:**

| 平台 | 检查方式 | 优先级 |
|------|---------|--------|
| ChatGPT | 直接在 ChatGPT 中搜索关键词 | 高 |
| Perplexity | 直接在 Perplexity 中搜索关键词 | 高 |
| Google AI Overview | Google 搜索中观察是否出现 AI 概述 | 高 |
| Kimi | 在 Kimi 中搜索（中国市场） | 中 |
| 豆包 | 在豆包中搜索（中国市场） | 中 |

**检查步骤:**
```
1. 在各 AI 搜索引擎中输入关键词
2. 记录:
   - 温州红龙是否被引用？ (YES/NO)
   - 被引用的具体内容片段？
   - 竞品是否被引用？哪些竞品？
   - 回答中有无不准确的信息？
3. 整理为 GEO 监控报告 → workspace/geo-monitor-report.md
```

## GEO 效果评估框架

| 指标 | 测量方法 | 目标 | 频率 |
|------|---------|------|------|
| AI 引用率 | 被引用次数 / 检查关键词数 | > 30% | 每周 |
| 传统搜索排名 | 手动搜索目标关键词位置 | 前 3 页 | 每月 |
| 社媒互动率 | (点赞+评论+分享) / 粉丝数 | > 3% | 每篇 |
| 询盘来源 | "从哪里找到我们的" | 提及搜索引擎/AI | 每月 |
| 内容产出量 | 每月发布篇数 | > 8 篇/月 | 每月 |

## 未引用补救策略

```
AI 搜索引擎没引用你
│
├─ Layer 1: 内容存在性检查
│   该关键词是否有对应内容？
│   → NO → 生成该关键词的内容（用 content-templates.md 中的模板）
│
├─ Layer 2: 内容结构检查
│   内容是否包含 AI 偏好的结构？
│   → FAQ 问答对？对比表格？有序步骤清单？
│   → 缺少 → 补充对应结构（这是最常见的原因）
│
├─ Layer 3: 平台可见性检查
│   内容是否发布在 AI 高频爬取的平台？
│   → LinkedIn (高) / Alibaba (高) / 行业论坛 (中) / Instagram (低)
│   → 只在低可见平台 → 转发到高可见平台
│
└─ Layer 4: 权威信号检查
    内容是否有足够的外部引用？
    → 其他内容中有交叉链接吗？
    → 有被评论/分享吗？
    → 没有 → 在其他内容中交叉引用 + 主动分享
```

## 30 天复盘机制

**复盘问题清单:**

1. 哪种内容类型互动最高？ → 加大投入
2. 哪种语言询盘转化最好？ → 优先该语言
3. 哪个平台效果最好？ → 集中资源
4. 哪些关键词被 AI 引用了？ → 生成更多同类内容
5. 哪些关键词没被引用？ → 按补救策略处理
6. 竞品有哪些新动作？ → 更新竞品差距矩阵

**复盘输出:** 更新 keyword-matrix.md 和 content-log.md
