## LinkedIn 优化规范

| 元素 | 规范 | 原因 |
|------|------|------|
| Hook（前 2 行） | 不超过 120 字符，含数字或反直觉观点 | LinkedIn 折叠只显示前 2 行 |
| 正文 | 800-1300 字符 | 最优互动长度 |
| 段落 | 1-2 句/段，每段之间空行 | 手机端可读性 |
| Hashtag | 3-5 个，放末尾 | 多了降低互动率 |
| 配图 | 必须，1200x627px | 有图的帖子互动率高 2 倍 |
| 发布时间 | 周二-周四 8-10AM (目标市场时区) | B2B 受众最活跃 |
| 结尾 | 用问题结尾 | 评论区活跃度驱动算法分发 |

**禁止:** "I'm excited to announce"、"humbled"、buzzword (synergy, leverage, ecosystem, disrupt, game-changer)

**Hook 公式:**
- "Most people get [topic] wrong. Here's what actually works:"
- "[Counterintuitive statement]."
- "[Number] things I learned from [experience]:"

## Facebook 优化规范

| 元素 | 规范 |
|------|------|
| 正文 | 100-250 词，口语化 |
| 配图 | 必须，产品图或信息图 |
| CTA | "Message us" / "Send inquiry" |
| 语言 | 用目标市场本地语言（不是英语） |
| 发布频率 | 每周 2-3 篇 |

## Alibaba 产品页优化规范

| 元素 | 规范 |
|------|------|
| 标题 | ≤ 128 字符，主关键词前置，含 CE/ISO |
| 主图 | 750x750px 以上，白底，多角度 |
| 卖点 | 5-8 个 bullet points，每点不超过 20 词 |
| 参数表 | 结构化表格，含单位 |
| FAQ | 5-8 个问答，覆盖采购常见疑问 |
| MOQ | 明确标注 |
| 交期 | 明确标注 |
| 更新频率 | 每 30 天更新一次（Algorithm 偏好活跃 listing） |

**标题公式:** `[主关键词] + [属性] + [认证] + [Factory Direct]`
**示例:** "Factory Direct Belt Vulcanizing Press 1200mm CE Certified Conveyor Belt Splicing Machine"

## Instagram 优化规范

| 元素 | 规范 |
|------|------|
| 标题 | ≤ 125 字符 |
| 正文 | 简短，视觉为主 |
| Hashtag | 20-30 个（Instagram 允许且有效） |
| 格式 | 多图轮播（Carousel）> 单图（效果好 1.4 倍） |
| Stories | 工厂实拍、生产过程、发货 |
| Reels | 15-30 秒产品演示 |

## 多语言本地化策略

**核心原则: 翻译 ≠ 本地化，每种语言独立创作**

| 市场 | 语言 | 内容风格调整 | CTA 风格 | 特殊处理 |
|------|------|------------|---------|---------|
| 南美 | 西班牙语 | 注重人际关系和信任建立，案例故事多 | "Contáctenos" / "Solicitar cotización" | 区分拉丁美洲西语和西班牙西语 |
| 中东 | 阿拉伯语 | 正式用语（MSA），尊重文化规范 | "تواصل معنا" | RTL 布局，保留英文产品名 |
| 独联体 | 俄语 | 技术文档风格，详细参数，数据驱动 | "Запросить цену" | 强调认证和质量保证 |
| 东南亚 | 印尼语 | 简洁直接，价格敏感，突出性价比 | "Hubungi kami" | 移动端优先，短段落 |
| 全球 | 英语 | 技术权威，数据驱动，专业但不过度正式 | "Get a quote" / "Contact us" | 标准 B2B 技术内容风格 |

### 阿拉伯语特殊处理

- 文字方向: RTL（right-to-left）
- 数字方向: LTR（混排时注意）
- 产品名: 保留英文产品名 + 阿拉伯语解释
- 禁止: 过于口语化的方言，使用标准阿拉伯语（MSA）

## 发布频率与内容日历

### 频率建议

| 平台 | 频率 | 内容类型分布 |
|------|------|------------|
| LinkedIn | 3-4 篇/周 | 技术教学 40% + 行业洞察 30% + 产品推广 20% + 公司文化 10% |
| Facebook | 2-3 篇/周 | 本地化内容 60% + 产品展示 25% + 客户案例 15% |
| Alibaba | 每 30 天更新 | 产品页优化 + FAQ 更新 |
| Instagram | 4-5 篇/周 | 产品图 40% + 工厂实拍 30% + 信息图 20% + 客户反馈 10% |

### 月度日历模板

```
第 1 周: 技术教学主题
- LinkedIn: 英文技术教学 (How-To)
- Facebook: 西语版教学
- Instagram: 技术参数信息图

第 2 周: 行业洞察主题
- LinkedIn: 英文数据驱动洞察
- Facebook: 阿拉伯语市场分析
- Instagram: 数据可视化图

第 3 周: 产品推广主题
- LinkedIn: 英文产品对比
- Facebook: 俄语选购指南
- Alibaba: 产品页更新
- Instagram: 产品实拍

第 4 周: 案例展示主题
- LinkedIn: 英文客户案例
- Facebook: 印尼语案例
- Instagram: 安装现场图
```
