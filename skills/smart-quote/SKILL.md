# 红龙工业 - 智能报价技能 v3.0

> **导航链：** 上游 ← [[company-research|企业背调]]（ICP评分输入）→ 下游 → [[quotation-generator|PDF报价单生成]] | 异议处理 → [[sales-champion|销冠决策引擎]] | Pipeline → [[sales]]

## 核心公式（v3.0 新增）

```
销售报价(外币) = 成本价(CNY) × (1 + 利润率%) ÷ 汇率

其中:
- 成本价: 从知识库 cost-prices 查询（未税人民币）
- 利润率: 按目标市场底线确定 + 背调加成
- 汇率: 当日中国银行现汇买入价（USD/CNY、EUR/CNY 等）
```

> **v3.0 更新**: 报价现在基于真实成本底价 + 动态汇率计算。不再用固定价格表。

## 报价流程（Step by Step）

### Step 1: 获取客户信息

**必须先问业务员**：
```
客户公司叫什么名字？（英文名）
目的国是哪里？
买什么产品？要多少量？
```

> 如果业务员只说"沙特客户"，一定要追问公司名！

### Step 2: 查产品成本价

**从知识库获取成本底价**：

```
// 搜索产品
kb_search(query="风冷机 三代 1200", type="products")

// 读取完整价目表
kb_read(type="products", name="cost-prices")
```

> 成本价在 `cost-prices.json` 中，244 个产品，字段: `code`(图号), `name_cn`, `name_en`, `spec`, `cost_price`(未税人民币)

### Step 3: 查当日汇率

**首选：Agent 内置工具 exchange_rate**
```
exchange_rate(currencies=["USD", "EUR", "GBP"])
// 返回: { USD: { cny_per_unit: 7.2500, formula_example: "cost * (1+margin) / 7.25" }, ... }
```

**工具返回示例：**
```json
{
  "ok": true,
  "date": "2026-06-01",
  "formula": "FOB价(外币) = 成本价(CNY) * (1 + 利润率) / 汇率",
  "rates": {
    "USD": { "currency": "美元", "cny_per_unit": 7.2500 },
    "EUR": { "currency": "欧元", "cny_per_unit": 7.8500 }
  }
}
```

**兜底方案（工具不可用时）：**
```bash
cd acquisition-agent && python skills/smart-quote/scripts/get-exchange-rate.py USD EUR
```
或 WebSearch "中国银行外汇牌价 当日日期"

| 汇率对 | 用途 |
|--------|------|
| USD/CNY | 美元报价（最常用） |
| EUR/CNY | 欧元报价 |
| GBP/CNY | 英镑报价 |

> 汇率波动 ±2% 以内直接使用；超过 2% 提醒业务员。脚本结果建议与中国银行官网交叉验证。

### Step 4: 检查是否已背调

**背调记录存储位置**：
1. **记忆文件**：检查 `MEMORY.md` 或当日 `memory/YYYY-MM-DD.md`
2. **CRM系统**：检查孚盟CRM中是否有该客户记录
3. **Pipeline客户池**：检查 `Pipeline客户池.xlsx`（如有）

**检查关键词**：
- 公司英文名
- 公司域名（bedrockco.sa → bedrockco.sa）
- 联系人邮箱

**判断逻辑**：
- **已有背调** → 读取ICP评分和关键信息，进入 Step 4
- **未背调** → 立即触发背调流程（调用 company-research）

### Step 3️⃣：客户背调（如需要）

使用 `company-research` 技能进行背调，重点获取：

| 维度 | 为什么要看 | 影响什么 |
|-----|-----------|---------|
| **企业规模** | 大公司付款好 | 可给较低利润率 |
| **行业匹配** | 制造业/木工/3D打印 | 直接影响产品选型 |
| **采购历史** | 是否有进口记录 | 判断付款能力 |
| **决策人** | 找到采购总监 | 影响沟通策略 |
| **ICP评分** | 综合评估 | 确定触达优先级 |

**背调完成后**，将结果保存到记忆文件（供下次使用）：
```markdown
## {公司名} 背调摘要
- 背调时间：{日期}
- 企业规模：{规模}（{员工数}人）
- 行业：{行业}
- ICP评分：{A/B/C/D}级（{分数}分）
- 付款能力：{描述}
- 报价有效期：{日期}
```

### 背调结果标准格式

从 `company-research` 获取后，提取以下字段映射到报价：

| 字段 | 背调来源 | 映射到 |
|-----|---------|--------|
| employee_count | LinkedIn/Crunchbase | 企业规模加成 |
| industry | 公司描述 | 行业匹配 |
| icp_score | 背调报告 | ICP加成 |
| payment_history | 海关记录/历史交易 | 付款方式加成 |
| customer_type | 公司业务描述 | 客户类型加成 |

### Step 5: 根据背调结果确定利润率区间

**计算基础**: 成本价(kb_read) × (1 + 利润率%) ÷ 汇率 = 销售报价(外币)

**利润率决定因素**：

| 因素 | 好的（大公司/老客户） | 差的（小公司/新客户） |
|-----|---------------------|---------------------|
| **企业规模** | 1000+人 → 低利润率 | 50人以下 → 高利润率 |
| **ICP评分** | A级 → 可优惠 | C/D级 → 保利润 |
| **客户类型** | 经销商 → 中等 | 终端用户 → 可高 |
| **付款方式** | T/T预付 → 可优惠 | OA赊账 → 保利润 |
| **订单量** | 批量大 → 薄利多销 | 小批量 → 高利润 |

**利润率区间速查表**（来自全球大客户战略地图）：

| 区域 | 优先级 | 代表国家 | 基础利润率 | 公式示例(USD) |
|------|--------|---------|-----------|------|
| 北美 | P0 | 美国、加拿大、墨西哥 | 65-85% | cost × 1.70 ÷ 7.25 |
| 欧洲 | P0 | 德/英/法/荷/意/西 | 40-55% | cost × 1.48 ÷ 7.85 |
| 中东/中亚 | P2 | 沙特、阿联酋、土耳其 | 45-55% | cost × 1.50 ÷ 7.25 |
| 南美 | P1 | 巴西、智利、阿根廷、秘鲁 | 40-55% | cost × 1.48 ÷ 7.25 |
| 非洲 | P3 | 尼日利亚、肯尼亚、埃及 | 45-60% | cost × 1.53 ÷ 7.25 |
| 独联体 | P3 | 俄罗斯、哈萨克、乌兹别克 | 40-50% | cost × 1.45 ÷ 7.25 |
| 东南亚 | P1 | 越南、印尼、菲律宾、泰国 | 30-45% | cost × 1.38 ÷ 7.25 |
| 南亚 | P2 | 印度、巴基斯坦、孟加拉 | 25-35% | cost × 1.30 ÷ 7.25 |
| 东亚 | P3 | 日本、韩国 | 25-35% | cost × 1.30 ÷ 7.25 |

> 公式: FOB价(USD) = 成本价(CNY) × (1 + 利润率%) ÷ USD/CNY汇率
> 成本价来源: kb_read(type="products", name="cost-prices")

## 背调加成规则

### 企业规模加成

| 规模 | 员工数 | 加成 |
|-----|-------|------|
| 微型 | 1-50 | +0% |
| 小型 | 50-200 | +5% |
| 中型 | 200-500 | +10% |
| 大型 | 500-1000 | +15% |
| 超大型 | 1000+ | +20% |

### ICP评分加成

| ICP等级 | 评分 | 加成 |
|--------|------|------|
| A级 | 75+ | +10% |
| B级 | 50-74 | +5% |
| C级 | 30-49 | +0% |
| D级 | <30 | -5%（谨慎）|

### 付款方式加成

| 付款方式 | 加成 |
|---------|------|
| T/T预付100% | +10% |
| T/T预付30% | +5% |
| L/C即期 | +0% |
| OA赊账 | -10% |
| 账期超60天 | -15% |

| 客户类型 | 说明 | 加成 |

## 🔒 报价锁定机制

> 客户问价 → 锁对话 → 发老板审批 → 等确认 → 发客户
> **未经此流程，绝不自行发送具体数字给客户**

### 触发条件

以下任何一种情况必须锁对话：

| 触发条件 | 示例 |
|---------|------|
| 客户问"多少钱"/"价格"/"报价"/"cost" | "how much for 3 units?" |
| 回复将包含具体数字+货币 | "$5,000", "€200/台", "¥36,000" |
| 承诺具体交货日期 | "can delivery by June 15" |
| 讨论付款条款 | "can you do T/T 30/70?" |

### 锁定流程

```
客户问价
  ↓
[锁对话] 回复："我来为您准备详细报价，稍等一下"
  ↓
生成报价草稿（利润率区间 + 价格范围 + 条款）
  ↓
发送老板审批（WhatsApp/邮件通知）
  ↓
等待确认，最长 2 小时
  ├── 1小时未回复 → 提醒老板
  └── 2小时未回复 → 告知客户"团队正在审核"，紧急升级通知老板
  ↓
老板确认 → 发送正式报价给客户 → 更新 CRM status=quote_sent
老板拒绝 → 按意见调整后重新提交
```

### 锁对话话术

**锁定时**（发给客户）：
```
"Absolutely, let me pull up the details for you — give me just a moment."
或
"I'll prepare a detailed quote for you right away. Our team reviews all quotes to ensure the best terms."
```

**超时提醒**（发给客户，2小时后）：
```
"Our team is finalizing your quote — you'll have it within the next couple of hours. Thanks for your patience!"
```

**升级通知**（发给老板，超2小时）：
```
[紧急] 报价审批超时
客户：[公司名] [邮箱]
等待时长：已超过 2 小时
客户需求：[产品] x [数量]
建议：直接联系客户或在系统中确认
```

## 🎯 授权矩阵

> 什么可以自主决定，什么必须升级老板审批

| 参数 | Agent 可自主决定 | 必须升级老板 |
|------|----------------|------------|
| **价格折扣** | ≤ 5% off 报价单价格 | > 5% off |
| **利润率底线** | 在铁律范围内（各国最低利润率）| 低于铁律利润率 |
| **付款条款** | T/T 30/70 / L/C at sight / T/T 100% | 非标准条款、OA赊账、账期>30天 |
| **交货时间** | 标准交期 ± 5天 | 超过 ± 5天，或需协调工厂 |
| **MOQ** | 目录MOQ（参考NAS产品规格） | 低于目录MOQ |
| **免费样品** | ≤ 2台标准样品 | > 2台，或非标准样品 |
| **质保条款** | 标准质保（12个月） | 延保、特殊条款 |
| **运费** | FOB上海/FOB深圳 | DDP、CIF、含保险等特殊条款 |
| **汇率** | 以报价当日汇率为准 | 客户要求锁定汇率超过7天 |
| **配色/标识** | 标准配色 | 非标配色、OEM定制标识 |

### 升级话术

客户要求超出授权时：
```
"This is a great question. Let me discuss this with our management team 
to see what we can do for you — I'll get back to you shortly."
```

同时立即通知老板：
```
[授权升级]
客户：[公司名]
超出权限：[具体要求，如"要求15%折扣，超出5%授权"]
当前报价：[报价单号及价格]
建议处理：[降价/拒绝/其他]
```

## 关键原则

### 价格计算公式 (v3.0)



### 成本价来源
- kb_read(type="products", name="cost-prices") — 244个产品的完整价目表
- kb_search(query="产品名 型号", type="products") — 搜索特定产品
- 成本价为未税人民币，2026-05 版本

### 汇率获取
- **首选**: exchange_rate 工具 — Agent 内置，直接返回汇率+报价公式
- **兜底**: Python 脚本 get-exchange-rate.py 或 WebSearch 中国银行外汇牌价
- 以中国银行当日现汇买入价为准
- 汇率波动 2% 以内直接用；超 2% 提醒业务员

### ⚠️ 红线（绝对不能破，来自全球大客户战略地图）

1. **北美最低利润率 70%**（Flexco 价差 3-5 倍，利润空间最大）
2. **欧洲最低利润率 45%**
3. **南美最低利润率 40%**
4. **东南亚最低利润率 30%**
5. **南亚最低利润率 25%**（印度/孟加拉/巴基斯坦价格战激烈）
6. **绝对不能低于成本价！**

### 💡 灵活空间

1. 利润率区间内，业务员可以灵活调整
2. 批量订单可以适当让利
3. 老客户可以给3-5%优惠
4. 非标产品可以加价10-30%

### 📝 记录要求

每次报价后，必须记录到当日 memory 文件：
- 报价日期
- 利润率
- 客户反馈
- 是否成单
