# Chrome 桌面操作技能

通过 desktop_screenshot + desktop_click + desktop_type + desktop_key 等工具操控 Chrome 浏览器。

## 核心原则

1. **地址栏是入口** — Ctrl+L 聚焦地址栏，比点击地址栏更可靠
2. **截图验证加载** — 页面跳转后截图确认加载完成，不要假设页面已就绪
3. **注意弹窗** — Chrome 的通知权限、Cookie 横幅、翻译提示可能遮挡目标元素
4. **标签页管理** — Ctrl+Tab/Ctrl+W 切换/关闭，不要用坐标点击标签

## 常用操作步骤

### 1. 打开网页

```
1. desktop_key("ctrl", "l")          — 聚焦地址栏
2. desktop_type(URL)                  — 输入网址
3. desktop_key("enter")              — 确认
4. 等待 2-3 秒
5. desktop_screenshot()              — 确认页面加载完成
```

### 2. 在页面中搜索文字

```
1. desktop_key("ctrl", "f")          — 打开查找栏
2. desktop_type(搜索词)              — 输入搜索词
3. desktop_key("enter")              — 跳转到第一个匹配
4. desktop_key("enter")              — 继续跳到下一个
```

### 3. 填写表单

```
1. 截图定位表单位置
2. desktop_click(x, y)              — 点击输入框
3. desktop_type(内容)                — 输入内容
4. desktop_key("tab")               — 跳到下一个字段
5. 重复输入直到完成
6. desktop_key("enter")             — 提交表单
7. desktop_screenshot()             — 确认提交结果
```

### 4. 下载文件

```
1. 截图确认下载按钮位置
2. desktop_click(下载按钮x, y)       — 点击下载
3. desktop_screenshot()             — 确认下载开始/保存对话框
4. 如弹出保存对话框：选择路径 → Enter
5. desktop_key("ctrl", "j")         — 打开下载列表确认
```

### 5. 管理多个标签页

```
1. desktop_key("ctrl", "t")         — 新建标签
2. 导航到目标页面
3. desktop_key("ctrl", "tab")       — 切回原标签
4. 完成操作后 desktop_key("ctrl", "w") — 关闭标签
```

## 陷阱与注意事项

### 页面加载
- SPA（单页应用）页面跳转不会触发浏览器加载指示器，截图确认最可靠
- 大型页面可能分段渲染，截图时内容可能不完整，等待后再截图
- 某些网站有反爬检测，快速连续操作可能触发验证码

### 弹窗与对话框
- Chrome 通知权限弹窗可能遮挡页面内容，先关闭再操作
- "是否离开此页面"确认框在关闭/刷新时出现，需要先处理
- 打印对话框（Ctrl+P）会覆盖整个页面，Esc 关闭

### 输入法
- 中文输入法激活时，字母键可能触发中文输入而非快捷键
- 操作前先按 Shift 或 Ctrl+Space 切换到英文输入模式
- 地址栏输入 URL 时确保在英文模式

### 缩放与 DPI
- 页面缩放影响坐标定位，操作前确认缩放比例（Ctrl+0 重置）
- 高 DPI 显示器截图分辨率可能与逻辑坐标不一致
- 使用 desktop_inspect 确认元素位置

### 下载
- 下载路径默认在用户目录的 Downloads 文件夹
- 大文件下载需要等待，可通过 Ctrl+J 查看进度
- 某些网站下载需要先接受条款或等待倒计时

## 推荐工作流

```
1. Ctrl+L 聚焦地址栏 → 输入 URL → Enter
2. 截图确认页面加载完成
3. 处理弹窗（关闭通知权限等）
4. 用 Tab 键在表单字段间导航
5. 输入完成后截图验证
6. Ctrl+S 保存（如需要）
```

## 与 desktop_inspect 配合

当不确定页面元素位置时：
```
1. desktop_screenshot()              — 查看页面布局
2. desktop_inspect(x, y)             — 探测目标位置的元素信息
3. 根据元素类型决定操作方式：
   - Edit/Text → 点击后 type
   - Button/Link → 直接点击
   - ComboBox → 点击后选择
```
