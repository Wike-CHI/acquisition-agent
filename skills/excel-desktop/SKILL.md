# Excel 桌面操作技能

> **Skill Graph：** 领域 → [[_index-meta|系统元技能领域]]


通过 desktop_screenshot + desktop_click + desktop_type + desktop_key 等工具操控 Excel。

## 核心原则

1. **截图先行** — 每次操作前先截图确认当前状态，操作后再截图验证结果
2. **快捷键优先** — Excel 大量操作可通过快捷键完成，比点击更可靠（不受 DPI/分辨率影响）
3. **tab 键导航** — 在单元格和工具栏间移动用 Tab/Enter，比坐标点击更稳定
4. **避免中文名** — 保存文件时用英文路径，避免中文路径导致的问题

## 常用操作步骤

### 1. 打开 Excel 文件

```
1. desktop_key("ctrl", "o")          — 打开文件对话框
2. desktop_screenshot()              — 确认对话框已打开
3. desktop_type(文件路径)             — 输入文件路径
4. desktop_key("enter")              — 确认打开
5. desktop_screenshot()              — 确认文件已打开
```

### 2. 在单元格中输入数据

```
1. desktop_key("f5")                 — 打开定位对话框
2. desktop_type(单元格地址如"A1")     — 输入目标地址
3. desktop_key("enter")              — 跳转
4. desktop_type(数据内容)             — 输入内容
5. desktop_key("enter")              — 确认
```

### 3. 输入公式

```
1. 定位到目标单元格（同上步骤1-3）
2. desktop_type("=")                 — 开始公式
3. desktop_type(公式内容如"SUM(A1:A10)")
4. desktop_key("enter")              — 确认
5. desktop_screenshot()              — 验证公式结果
```

### 4. 设置单元格格式

```
1. 选中目标区域（可用 Ctrl+Shift+方向键 扩展选区）
2. desktop_key("ctrl", "1")          — 打开格式对话框
3. desktop_screenshot()              — 确认对话框打开
4. 根据需要点击对应标签页（数字/对齐/字体/边框等）
5. 设置完成后按 Enter 确认
```

### 5. 插入图表

```
1. 选中数据区域
2. desktop_key("alt", "F1")          — 快速插入柱状图
3. desktop_screenshot()              — 确认图表已插入
4. 如需切换图表类型：右键图表 → 更改图表类型
```

### 6. 保存为 CSV

```
1. desktop_key("f12")                — 另存为
2. desktop_screenshot()              — 确认对话框
3. 点击保存类型下拉框
4. 选择 "CSV (逗号分隔)(*.csv)"
5. 选择保存路径
6. desktop_key("enter")
7. desktop_screenshot()              — 确认保存成功
```

## 陷阱与注意事项

### 坐标点击陷阱
- Excel 的 Ribbon 标签在不同版本（2016/2019/365）位置可能不同
- 缩放比例影响坐标，建议用快捷键而非点击按钮
- 双显示器时截图可能只包含主显示器

### 输入陷阱
- 中文输入法可能干扰：先切到英文输入法再操作
- 数字格式：输入前确认单元格不是文本格式，否则 SUM 等公式不生效
- 日期格式：Excel 的日期格式受系统区域设置影响
- 超长数字：超过 15 位精度丢失，需要先设为文本格式再输入

### 对话框陷阱
- "另存为" 对话框中 CSV 格式只保存当前工作表
- 替换操作没有明确的"完成"提示，需要截图确认
- 筛选模式下复制粘贴可能只操作可见行

### 保存陷阱
- CSV 保存会弹出"不兼容功能"警告，需要点"是"继续
- 同时打开多个文件修改时，Ctrl+S 保存的是当前活跃的工作簿
- 关闭时如果未保存会弹出保存提示

## 推荐工作流

```
1. 截图确认当前状态
2. 用快捷键定位到目标位置
3. 输入/修改内容
4. 截图验证结果
5. 保存
6. 截图确认保存成功
```

## 与 desktop_inspect 配合

当不确定 UI 元素的位置或属性时，用 desktop_inspect 探测：
```
1. desktop_screenshot()              — 先看整体布局
2. 根据截图估算目标坐标
3. desktop_inspect(x, y)             — 探测该位置的 UI 元素
4. 确认元素名称和控制类型
5. 决定用点击还是快捷键操作
```
