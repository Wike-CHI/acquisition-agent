# 外贸客户5招背调法 v2.0

> **Skill Graph：** 领域 → [[_index-discovery|客户发现与调研领域]] | 上游 ← [[_index-discovery|客户发现领域]] | 下游 → [[company-research|深度背调]]（初筛通过后）


输入海外企业名称（英文），5步递进式搜集公开信息，输出结构化背调报告。

适合**快速判断客户是否值得投入精力开发**，不是深度背调（深度背调用 `company-research`）。

---

## 何时使用 / 何时不使用

### 使用场景
- 首次接触一家海外企业，需要快速了解全貌
- 决定是否值得投入精力进一步开发
- 为开发信收集个性化素材
- 批量筛选潜在客户

### 不使用场景
- 已确认目标客户需要深度背调 → 用 `company-research`（6+6维度，三轮搜索）
- 需要区域市场分析 → 用 `market-research`（六维度市场框架）
- 需要竞品对标分析 → 用 `customer-intelligence`
- 需要方法论级别的深度调研 → 用 `deep-research`

## 核心流程

```
输入：公司名（英文）
       ↓
[Step 1] 平台信息搜索 → 企业基础画像
       ↓
[Step 2] 海关数据分析 → 采购能力评估
       ↓
[Step 3] SNS社媒调研 → 决策人挖掘
       ↓
[Step 4] 谷歌搜索+地图街景 → 真实性验证+补充
       ↓
[Step 5] 官网深度分析 → 业务洞察
       ↓
输出：结构化背调报告 + ICP评分 + 行动建议
```

### 关键规则（5条）

| # | 规则 | 为什么 |
|---|------|--------|
| 1 | **按顺序执行** | 前一步结果指导后一步搜索方向，跳步会遗漏关键信息 |
| 2 | **每步限时评估** | 某步已获取充分数据则标记"信息充分"后进入下一步，节省搜索配额 |
| 3 | **交叉验证** | 至少两个独立来源确认才能标注"已验证"，单来源标注"待验证" |
| 4 | **只输出搜到的** | 禁止编造，搜不到的维度直接跳过不输出，不要写"暂无" |
| 5 | **防混淆** | 严禁混入名称相近但不是目标企业的信息 |

## 搜索工具

主力：内置 web_search + web_fetch（本运行时可用）。如需 Exa MCP 专业搜索能力且 mcporter 可用时使用。

```bash
# 优先使用内置 web_search
web_search({query: "test", numResults: 1})
# 如需专业搜索能力，尝试：
mcporter call exa.web_search_exa 'query=test&numResults=1'
```

URL 拼接规则：所有输出 URL 必须包含 `https://` 前缀。

## Step 1：平台信息搜索

**目标**：建立企业基础画像 — 性质、规模、行业、产品线

| # | 搜索指令 | 工具 | 提取信息 |
|---|---------|------|----------|
| 1.1 | `exa.company_research_exa query={公司名}` | company_research | 官网、总部、行业、员工数 |
| 1.2 | `exa.web_search_exa query="{公司名} company profile headquarters industry"` | web_search | 业务范围、成立年份、子公司 |
| 1.3 | `exa.web_search_exa query="site:linkedin.com/company {公司名}"` | web_search | LinkedIn 企业页、员工总数 |

### Step 1 输出 checklist

```
□ 企业性质：制造商 / 贸易商 / 经销商 / 服务商
□ 行业分类：[具体行业]
□ 规模线索：员工数、成立年份
□ 官网 URL：[完整 URL]
□ 主营产品：[产品线列表]
□ 企业标签：上市公司 / 家族企业 / 跨国集团等
```

---

## Step 2：海关数据分析

**目标**：评估采购能力和贸易活跃度

| # | 搜索指令 | 工具 | 提取信息 |
|---|---------|------|----------|
| 2.1 | `exa.web_search_exa query="{公司名} import export trade customs"` | web_search | 进出口品类、贸易伙伴 |
| 2.2 | `exa.web_search_exa query="{公司名} shipment records bill of lading"` | web_search | 贸易频率、采购规模 |
| 2.3 | `exa.web_search_exa query="{公司名} procurement sourcing supplier equipment"` | web_search | 当前供应商、采购需求 |

### Step 2 输出 checklist

```
□ 贸易活跃度：高 / 中 / 低 / 无公开记录
□ 进口品类：[相关品类列表]
□ 采购规模：[估算]
□ 已知供应商：[供应商名称列表]
□ 中国采购线索：[有 / 无 / 负面印象]
```

> 海关公开数据有限，搜不到不代表无贸易活动。明确标注"公开数据未检索到"而非臆测。

---

## Step 3：SNS社媒调研

**目标**：找到关键决策人和联系方式

| # | 搜索指令 | 工具 | 提取信息 |
|---|---------|------|----------|
| 3.1 | `exa.people_search_exa query="{公司名} CEO director procurement manager"` | people_search | 决策者姓名、职位 |
| 3.2 | `exa.web_search_exa query="site:linkedin.com/in {公司名} procurement OR buyer OR director"` | web_search | 个人简介、邮箱线索 |
| 3.3 | `exa.web_search_exa query="{公司名} site:facebook.com OR site:twitter.com"` | web_search | 公司社媒活跃度 |

### Step 3 输出 checklist

```
□ 关键决策人（按优先级排序）：
  1. [姓名] - [职位] - [LinkedIn URL] - [邮箱，如有]
  2. [姓名] - [职位] - [LinkedIn URL]
□ 社媒活跃度：高 / 中 / 低
```

> **邮箱铁律**：必须决策人邮箱。info@/sales@/contact@ 等通用邮箱视为无效，不记录。

---

## Step 4：谷歌搜索+地图街景

**目标**：验证企业真实性，补充上下文信息

| # | 搜索指令 | 工具 | 提取信息 |
|---|---------|------|----------|
| 4.1 | `exa.web_search_exa query="{公司名} address location Google Maps"` | web_search | 实际地址 |
| 4.2 | `exa.web_search_advanced_exa query="{公司名} news expansion" startPublishedDate=2025-01-01` | advanced | 近期新闻、扩张动态 |
| 4.3 | `exa.web_search_exa query="{公司名} project tender contract expansion"` | web_search | 项目动态、设备需求 |
| 4.4 | `exa.web_search_exa query="{公司名} jobs careers procurement buyer"` | web_search | 采购相关招聘→采购需求信号 |

### Step 4 输出 checklist

```
□ 地址验证：真实运营地址 / 虚拟办公 / 无法验证
□ 运营规模判断：[基于地址和地图的推断]
□ 近期动态：[重要新闻/项目/合作]
□ 招聘信号：[有/无，具体职位]
```

---

## Step 5：官网深度分析

**目标**：深入理解业务模式、产品线、发展战略

| # | 分析对象 | 工具 | 提取信息 |
|---|---------|------|----------|
| 5.1 | 官网产品页 | `exa.crawling_exa urls=[产品页URL]` | 产品线、规格、应用场景 |
| 5.2 | About/Company 页 | `exa.crawling_exa urls=[about页URL]` | 企业文化、历史、价值观 |
| 5.3 | News/Blog 页 | `exa.crawling_exa urls=[news页URL]` | 近期动态、技术方向 |
| 5.4 | Contact 页 | `exa.crawling_exa urls=[contact页URL]` | 完整联系方式、分公司 |

### Step 5 输出 checklist

```
□ 核心产品线：[详细产品列表]
□ 目标市场：[主要销售区域]
□ 技术能力：[认证、专利、研发投入线索]
□ 发展方向：[新品、新市场、战略规划]
□ 完整联系方式：[地址 / 电话 / 邮箱]
```

> 如官网 URL 在 Step 1 已获取，直接用。多个子页面用逗号分隔的 URL 数组一次 crawling。

## 与其他技能的关系

| 技能 | 关系 | 使用场景 |
|------|------|---------|
| `company-research` | 深度版背调 | 5招背调 ICP≥75 后，用此技能深入 |
| `customer-intelligence` | 综合情报 | 需要竞品+市场+客户全方位分析时 |
| `cold-email-generator` | 下游消费 | 背调报告中的行动建议→生成开发信 |
